# 功能计划模板

将下方模板复制到 `docs/plans/YYYY-MM-DD-feature-name.md`，替换占位内容。先写清用户能看到的行为和验收条件，再列实现步骤。按 [协作规则](../AGENTS.md) 确认和更新计划。流程参考 [GitHub Spec Kit 的规格驱动开发说明](https://github.com/github/spec-kit/blob/main/spec-driven.md)。

## 导航性能对照

- 以 GoLand 实际执行的导航查询为性能基准。在同一主机固定 GoLand 构建号、rs-gopls 发布版、项目修订、Go SDK、搜索范围、打开文件和编辑序列。
- 每次计时都核对完整目标集合和标识符范围。用结果一致的样本比较耗时，将搜索范围、落点和错误有差异的样本单列。
- 分别记录索引就绪后的新查询、重复同一查询和编辑后的查询。报告 P50/P95 和样本数，并注明结果缓存状态、计时起止点及是否包含界面操作。衡量启动时，按双方相同的起止点单列到首次正确结果的耗时。记录峰值工作集时注明进程范围和采样方式。
